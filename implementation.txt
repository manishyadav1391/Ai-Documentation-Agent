#### Issue #4: Ctrl+C / Ctrl+V / Ctrl+A control characters

##### [MODIFY] [keyboard_tracker.py](file:///c:/doc_automation/user_manual_bot%20using%20screen%20recoder/recorder/keyboard_tracker.py)

- In `_on_press`, when `key.char is not None`, check if `ord(key.char) < 32` (control character range `\x00–\x1f`). If so, **ignore** the keypress entirely.
- This catches Ctrl+C (`\x03`), Ctrl+V (`\x16`), Ctrl+A (`\x01`), Ctrl+Z (`\x1a`), etc.

```python
if hasattr(key, 'char') and key.char is not None:
    # Ignore control characters (Ctrl+C, Ctrl+V, Ctrl+A, etc.)
    if ord(key.char) < 32:
        return
    ...
```

#### Issue #5: Single Character Inputs

##### [MODIFY] [keyboard_tracker.py](file:///c:/doc_automation/user_manual_bot%20using%20screen%20recoder/recorder/keyboard_tracker.py)

- In `flush()`, after building `typed_text`, check `len(typed_text) < 2`. If so, clear buffer and return without calling the callback.
- This prevents stray single-character events (e.g., pressing "v" after Ctrl+V) from becoming documentation steps.

```python
typed_text = "".join(self.buffer).strip()
self.buffer = []

if not typed_text or len(typed_text) < 2:
    self.field_info = None
    self.is_sensitive = False
    return None
```

### Sprint 2 continued — Duplicate Click Filter (Issue #11)

#### Issue #11: Duplicate Clicks

##### [MODIFY] [recorder.py](file:///c:/doc_automation/user_manual_bot%20using%20screen%20recoder/recorder/recorder.py)

- Track `self.last_click_info = {"element": None, "window": None, "time": None}`.
- In `_handle_click`, after resolving element_name, check if same element + same window within 1.0 second → skip.

```python
import time as time_mod

now = time_mod.time()
click_key = (element_name, win_info.get("hwnd"))
if (self.last_click_info.get("key") == click_key and
    now - self.last_click_info.get("time", 0) < 1.0):
    return  # duplicate click, skip
self.last_click_info = {"key": click_key, "time": now}
```

#### Issue #14: Window Classification

- Add `window_type` classification to `get_active_window_info()`:

```python
BROWSER_PROCESSES = {"chrome.exe", "msedge.exe", "firefox.exe", "brave.exe", "opera.exe", "arc.exe", "vivaldi.exe"}
OFFICE_PROCESSES = {"excel.exe", "winword.exe", "powerpnt.exe", "outlook.exe", "onenote.exe"}

def classify_window(proc_name, class_name):
    if proc_name in BROWSER_PROCESSES:
        return "browser"
    if proc_name in OFFICE_PROCESSES:
        return "office"
    if proc_name == "explorer.exe":
        return "file_explorer"
    if class_name == "ConsoleWindowClass":
        return "terminal"
    return "desktop_app"
```
